# Third-party components and attribution

This repository provides a desktop registration and annotation workflow. It does not claim authorship of the underlying third-party libraries, algorithms or foundation models.

| Component | Use | Source |
|---|---|---|
| OpenCV | Feature matching, affine estimation, ECC and image processing | https://github.com/opencv/opencv |
| NumPy | Array operations | https://github.com/numpy/numpy |
| Pillow | Image I/O and Tkinter display | https://github.com/python-pillow/Pillow |
| Python / Tkinter | Desktop UI and runtime | https://www.python.org/ |
| scikit-image | Polygon contour round-trip tests | https://github.com/scikit-image/scikit-image |
| SAM Workbench API | Optional external session-based SAM server | https://github.com/siyuvision/sam-workbench-api |
| samapi | Upstream of SAM Workbench API | https://github.com/ksugar/samapi |
| SAM 2 / SAM 3 | Optional segmentation models served externally | https://github.com/facebookresearch/sam2 / https://github.com/facebookresearch/sam3 |
| LightGlue / SuperPoint | Optional enhanced matching | https://github.com/cvg/LightGlue |

No third-party model weights, SAM server source, vendored dependency packages or experimental images are distributed here. Install external components from their respective upstream sources and follow their licenses and model access terms.

No open-source license grant for this repository's application code is included in this initial portfolio publication. Public availability alone is not a blanket permission to redistribute the application. Third-party components retain their own licenses; this note does not replace those licenses.
